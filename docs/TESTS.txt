Limits of validation:
The maintainer confirmed 0.3.3 works in a real Windows client. The 0.3.4 review
fixes still require one final live smoke test. Mock GUI checks do not prove
pixel layout or every native event timing. Installer tests do not prove real
Docker daemon behavior beyond the original deployment already exercised by the maintainer.
First in-game check: open the bottom-right shortcut, review all three tabs, create a
circuit rule, verify its live value, save it, then test and acknowledge a safety pause.
