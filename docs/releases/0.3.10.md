# Factory Night Watch 0.3.10

Published on the [Factorio Mod Portal](https://mods.factorio.com/mod/factory-night-watch)
on 2026-10-31. Maintainer: dermalla. License: MIT.

## Changes since 0.3.7

- Named rectangular structure-loss exclusions on individual planets/platforms.
- Persistent, player-specific area outlines in world and map views, with explicit
  return controls and saved/unsaved/stale status. Save and return applies pending settings.
- A native picker and editable list for exact building-prototype exclusions,
  covering every quality on all monitored surfaces.
- Area and building exclusions coexist with the wall/robot switches. Explicit
  circuit rules, research and offline-time limits remain active.
